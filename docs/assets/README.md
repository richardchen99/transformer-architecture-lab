[`architecture.svg`](architecture.svg) is an original, editable vector schematic prepared for this repository. [`architecture.png`](architecture.png) is its 3,200-pixel-wide raster export. The diagram distinguishes the computed attention core from conceptual architecture and generation views; see the [README](../../README.md#computation-and-scope) for scope.

No screenshot is a synthetic interface image. The framework diagram is drawn with vector shapes and text, not generated by a text-to-image model. Figures contain no editor windows, browser chrome, local paths, or private account details. Numerical values illustrate the stated experiment and are not performance benchmarks.
